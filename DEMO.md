# Демонстрация Career Quest — 5–7 минут

## Подготовка

Запустите приложение из каталога проекта: `.\run.ps1`. Если зависимости уже установлены и PowerShell запрещает сценарии: `.\.venv\Scripts\python.exe scripts\start.py`.

При первом запуске задайте отдельные пароли сотрудника и HR. Используйте обычное окно браузера для HR и отдельный профиль браузера или приватное окно для сотрудника: вкладки одного профиля делят cookie. Откройте <http://127.0.0.1:8000>.

В HR-кабинете при необходимости введите ключ OpenAI. Он действует до завершения процесса сервера. Статус «ключ введён» ещё не подтверждает работу провайдера: при показе рекомендаций проверьте отметку AI. Без ключа или при ошибке честно показывается резервный подбор.

## 1. Импорт и проверочные профили

В HR загрузите вместе `tests/fixtures/employees.json` и `tests/fixtures/activity_history.csv`. Это собственные синтетические контрольные примеры, а не официальные профили жюри. После успешного импорта нажмите появившийся ID для просмотра.

- `CONTROL_CRITICAL`: публичные выступления — самый низкий навык, но для следующего грейда критичен System Design; в истории есть повторные пропуски похожих событий. Покажите реальные причины выбора и числовой предпросмотр, не обещайте определённый ответ LLM заранее.
- `CONTROL_PREREQUISITES`: отсутствующие навыки равны нулю, мероприятия с невыполненными предпосылками исключены.
- `CONTROL_REPEAT`: завершённый ранее клуб `EV_036` может рекомендоваться повторно, если он подходит по остальным правилам.

HR просматривает профиль, но не выполняет мероприятия от лица сотрудника. Вернуться к агрегатам можно через «Обзор HR».

## 2. Выполнение от лица сотрудника

После импорта создайте отдельный аккаунт локальной командой администратора:

```powershell
.\.venv\Scripts\python.exe scripts\create_account.py --username demo-critical --role employee --employee-id CONTROL_CRITICAL
```

Задайте пароль в скрытом приглашении. Если аккаунт уже создан, используйте его: команда не заменяет пароль существующего логина. В отдельной браузерной сессии войдите этим аккаунтом.

Покажите профиль, требования, критичные навыки и рекомендацию. В карточке видны расчёт `текущий уровень → после выполнения`, требуемый уровень и ближайшая сессия либо доступность в любое время. Предпросмотр ничего не записывает и не гарантирует кадрового повышения.

Нажмите «Выполнить» у выбранной подходящей активности. Покажите сообщение с фактическими изменениями навыков и пересчитанные рекомендации. Действие записывается в локальную базу; повторная демонстрация на том же профиле уже использует новую историю. Не удаляйте рабочую базу ради повторного показа.

Если дата последней оценки совпадает с датой среза, выполнение заблокировано с объяснением. Нельзя подделывать дату: для такого профиля нужен корректный более поздний срез. У поставляемых контрольных профилей оценка предшествует срезу.

## 3. HR и приватность

Обновите HR-страницу. Покажите дефициты выбранной роли/грейда после изменения прогресса. Поясните: список для диалога основан на повторных пропусках/отказах/незавершениях, не является прогнозом увольнения; одно завершение не стирает прошлые записи.

В кабинете сотрудника нет чужих профилей, HR-аналитики и переключателя ролей. Для демонстрации доступа используйте разные аккаунты, не клиентскую подмену роли.

## Что подчеркнуть

- LLM выбирает из разрешённых добровольных мероприятий и выбирает основания; приложение проверяет их и строит текст по фактам.
- Рост вычисляется по `gain`, `max_level`, дате оценки и дате среза; обязательные мероприятия не рекомендуются.
- Три языка доступны через переключатель, исходный язык берётся из профиля.
- Дополнительные профили жюри загружаются тем же способом без изменения кода.
- Датасет используется только в разрешённых рамках хакатона; ключи и пароли не включаются в демонстрационные материалы.
