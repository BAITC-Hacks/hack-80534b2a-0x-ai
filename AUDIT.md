# Проверка Career Quest — 23 сентября 2026

## Объём

Три субагента проверили соответствие DOCX ТЗ и расчёты, безопасность кошелька и обменов, frontend и локализацию. Основной агент выполнил общий Python-прогон и сценарии браузера на отдельном сервере с временной SQLite. Рабочие профили, балансы и история в этом аудите не изменялись. Реальный OpenAI не вызывался, ключ не использовался.

## Результаты

- JS harness `node tests/test_rewards_ui.cjs` прошёл: локализации, фокус, постоянная область уведомлений и две гонки ответов кошелька.
- 95/95 Python-тестов прошли за 20,448 с. Новые файлы: tests/test_rewards_functional.py (11), tests/test_rewards_security.py (8).
- Проверены доступ только владельца кошелька, запрет HR, CSRF/Origin, подмена employee_id, no-store, обязательные/будущие/незавершённые события, однократное начисление и EV_036 раз в месяц.
- Параллельные обмены не создают отрицательный баланс. Повторы одного request_id списывают XP один раз. Ошибка записи XP откатывает завершение активности.
- Импорт, сохранение цели/кодов, независимость навыков и рекомендаций от обмена подтверждены тестами.
- В браузере: 500 XP → обмен кино за 300 → 200 XP; выполнение активности → 300 XP и прирост двух навыков; обмен кофе за 150 → 150 XP. Коды сохраняются после обновления. Проверены ru/kk/en и ширина 390 px, горизонтального переполнения страницы нет, ошибок JavaScript не обнаружено.

- В истории XP показаны локализованные названия активностей.
- В DEMO.md добавлен сценарий наград.

## Открытые вопросы и границы

1. Реальный AI остаётся неподтверждённым на всех контрольных сценариях. Сохранённый openai-verification.json содержит ошибку missing_independent_factors у CONTROL_CRITICAL. Последний отдельный UI-прогон дал AI для E0002/E0003 и fallback для E0004; причина последнего не определена. Три обычных профиля не заменяют контрольные сценарии.
2. JSON Schema позволяет три произвольных factor_keys, но сервер требует activity_fit, history_fit и gap/goal. Необходимо согласовать контракт модели с проверкой, затем повторить живой прогон.
3. XP — только демонстрационная экономика: одинаковые 100 XP, самоподтверждение выполнения, доверенный импорт. Нет партнёрских интеграций, настоящих купонов, проверки наставником или взвешивания наград по усилиям. Отдельный маршрут с наградой за его завершение не реализован, есть рубеж 300 XP. Это опциональная часть DOCX ТЗ.
4. Полная задержка UI ≤2 с и AI ≤10 с под нагрузкой этим аудитом не измерялась. Прохождение тестов не является гарантией отсутствия всех уязвимостей.
